# ESP32 บัตร NFC เปิดประตู 🔑

แตะบัตรที่อยู่ในรายชื่อ กลอนไฟฟ้าปลดล็อก 3 วินาที แล้วล็อกกลับเอง ไม่ต้องต่อเน็ต ไฟดับแล้วเปิดเครื่องใหม่ก็ยังจำบัตรได้

จากคลิป **K iTech Review** (TikTok) · **Kham iTech Lab** (YouTube / Facebook)

## ของที่ใช้

| ชิ้น | หมายเหตุ |
|---|---|
| บอร์ด ESP32 | รุ่นไหนก็ได้ |
| โมดูลอ่านบัตร PN532 | แบบแผงสีแดง/ฟ้า ที่มีสวิตช์เลือกโหมด |
| รีเลย์ 1 ช่อง | คุมกลอน |
| กลอนไฟฟ้า 12V | แบบ solenoid หรือกลอนแม่เหล็ก |
| อะแดปเตอร์ 12V | แยกให้กลอน |
| บัตร / พวงกุญแจ NFC (13.56MHz) | แบบ MIFARE Classic หรือ NTAG |
| ปุ่มกด (ไม่ใส่ก็ได้) | เปิดจากด้านใน |

## ต่อสาย

| อุปกรณ์ | ขา | ต่อเข้า |
|---|---|---|
| PN532 | VCC | 3.3V |
| | GND | GND |
| | SDA | GPIO 21 |
| | SCL | GPIO 22 |
| รีเลย์ | VCC | 5V / VIN |
| | GND | GND |
| | IN | GPIO 26 |
| ปุ่มด้านใน | ขาหนึ่ง | GPIO 27 |
| | อีกขา | GND |

- **ตั้งสวิตช์บนโมดูล PN532 เป็นโหมด I2C** (ดูตารางเล็ก ๆ ที่พิมพ์บนแผง) ขา IRQ กับ RSTO ไม่ต้องต่อ
- กลอนไฟฟ้า: 12V จากอะแดปเตอร์ → COM ของรีเลย์ → NO → กลอน → กลับ GND ของอะแดปเตอร์

## ติดตั้ง

1. เปิด Arduino IDE ติดตั้งบอร์ด ESP32 (Boards Manager → esp32 by Espressif)
2. ติดตั้งไลบรารี **Adafruit PN532** (Library Manager จะถามให้ลง Adafruit BusIO ด้วย กด Install All)
3. เปิดไฟล์ `nfc_door/nfc_door.ino` แล้วอัปโหลด

## เพิ่มบัตร

1. เปิด Serial Monitor ที่ 115200
2. แตะบัตร จะขึ้นว่า `บัตรไม่อยู่ในรายชื่อ UID: 04:A1:B2:C3`
3. ก๊อปเลขนั้นไปใส่ใน `ALLOWED` ในโค้ด เพิ่มได้หลายใบ แล้วอัปโหลดใหม่

```cpp
const char *ALLOWED[] = {
  "04:A1:B2:C3",   // บัตรพ่อ
  "7F:22:1C:9A",   // พวงกุญแจแม่
};
```

## ค่าที่ปรับได้

| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `UNLOCK_MS` | 3000 | ปลดกลอนนานกี่มิลลิวินาที |
| `RELAY_ACTIVE_LOW` | true | ถ้ากลอนปลดค้างตั้งแต่เปิดเครื่อง เปลี่ยนเป็น `false` |
| `SAME_CARD_MS` | 2000 | แตะบัตรค้างไว้ ไม่นับซ้ำ |

## ข้อควรรู้

- **บัตรรุ่นถูกก๊อปเลข UID ได้** โปรเจกต์นี้เช็กแค่เลขบัตร เหมาะกับห้องในบ้าน ห้องเก็บของ ตู้ ประตูหน้าบ้านควรมีกุญแจอีกชั้น
- **เลือกชนิดกลอนให้ถูก**: กลอนแบบ "ไฟดับแล้วล็อก" (fail-secure) ไฟดับเข้าไม่ได้ ส่วนแบบ "ไฟดับแล้วเปิด" (fail-safe เช่นกลอนแม่เหล็ก) ไฟดับประตูเปิดเอง ควรมีทางเปิดสำรองเสมอ
- กลอน solenoid กินกระแสสูงตอนดึง ใช้อะแดปเตอร์ 12V ที่จ่ายได้อย่างน้อย 2A

## ปัญหาที่เจอบ่อย

- **ขึ้น "หา PN532 ไม่เจอ"**: สวิตช์โหมดยังไม่ใช่ I2C หรือสลับสาย SDA/SCL
- **กลอนปลดค้างตั้งแต่เปิดเครื่อง**: แก้ `RELAY_ACTIVE_LOW = false`
- **อ่านบัตรไม่ติด**: บัตร 125kHz (แบบบัตรคีย์การ์ดรุ่นเก่า) ใช้กับ PN532 ไม่ได้ ต้องเป็นบัตร 13.56MHz
